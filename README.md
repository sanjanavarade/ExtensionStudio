# ✨ StudioCute – Builder App Chrome Extension

A **lightweight, privacy-first Chrome extension** that helps everyday internet users browse smarter, calmer, and more intentionally — without clutter, tracking, or complexity.

Built to feel *native*, *trustworthy*, and *worthy of the Chrome Web Store*.

---

## 🌟 Why StudioCute?

Most Chrome extensions either:
- Do **too little** (basic counters, plain notes), or
- Do **too much** (heavy tracking, unnecessary permissions)

**StudioCute** is different.

It focuses on **real daily browsing problems** and solves them with:
- Simple interactions
- Clean UI
- Zero data selling
- Minimal permissions
- Offline-first thinking

---

## 🧩 What Can It Do?

StudioCute offers **purpose-built tools** that feel like magic — but behave responsibly.

### 🔹 ContextPilot  
**Sparkle-Powered Reading Helper**

- Reduces information overload while reading
- Helps users understand long articles faster
- Keeps focus without opening new tabs
- Works fully offline after page load

**Best for:**  
Students, readers, professionals, and anyone tired of tab chaos.

---

### 🔹 MindfulFlow  
**Your Zen Browsing Buddy**

- Gently breaks infinite scrolling loops
- Encourages healthier browsing habits
- No blocking. No guilt. Just awareness.
- Zero tracking, zero analytics

**Best for:**  
Anyone who wants control over their time — not more rules.

---

### 🔹 SnippetVault  
**The Secure Clipboard Cleaner**

- Automatically clears sensitive copied data
- Prevents passwords or private text from lingering
- Everything stays local — always

**Best for:**  
Privacy-conscious users, remote workers, everyday internet users.

## 🛠️ Tech Stack

- **Chrome Extension:** Manifest V3
- **Language:** JavaScript (ES6+)
- **Architecture:** Modular & feature-based
- **Storage:** Chrome Local Storage (no cloud sync)
- **UI:** Lightweight HTML + CSS
- **Performance:** No background abuse, event-based execution

---

## 🔐 Privacy First (Non-Negotiable)

StudioCute:
- ❌ Does NOT collect personal data
- ❌ Does NOT track browsing history
- ❌ Does NOT use analytics or trackers
- ❌ Does NOT send data to any server

✅ All processing happens **locally in your browser**  
✅ Works offline wherever possible
